## About

Git CalVer Generator is a GitHub Action that automatically generates Calendar Versioning (CalVer) tags for your projects. It simplifies version management by using date-based versioning schemes like `YYYY.MM.DD` or `YYYY.0M.0D`.

## Features

- **Automatic CalVer Generation**: Creates version tags based on calendar dates
- **Flexible Format**: Supports various CalVer formats
- **Easy Integration**: Simple to add to your GitHub Actions workflow
- **Time-Saving**: No manual version bumping required
